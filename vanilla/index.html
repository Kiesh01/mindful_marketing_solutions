Common Inquiries

Frequently asked questions.

How do you prevent conflict of interest between commercial and NGO partners?

We maintain two strictly segregated balance sheets and a legally binding Cross-Sector Code of Ethics. Commercial brands get real market penetration and verified ESG outcomes; NGOs receive dedicated private-sector financing without sacrificing editorial or operational autonomy.

Is this code 100% vanilla HTML, CSS, and JS?

Yes. This entire directory contains zero npm/build dependencies. You can double-click index.html in any browser or drop it directly into any cPanel, GitHub Pages, Netlify, or Apache/Nginx web server.

How is mobile responsiveness ensured?

Our pure CSS utilizes fluid CSS clamp typography, CSS flexbox and grid layouts, touch targets adhering to the minimum 44px standard, touch-friendly drawers, and dedicated media queries spanning 320px to 4K displays.

What East African languages are supported?

Our core language pool spans Swahili (Tanzanian & Kenyan), Nairobi Sheng, Kikuyu, Dholuo, Kalenjin, Luhya, Kamba, Luganda, Runyankole, and Kinyarwanda, with in-country native speaker sign-offs.
