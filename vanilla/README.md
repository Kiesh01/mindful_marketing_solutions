# Mindful Marketing Solutions — Pure HTML, CSS & JavaScript

This folder contains the complete **Mindful Marketing Solutions** website written in **100% pure vanilla HTML5, CSS3, and JavaScript**.

## Features Included
- **Zero build dependencies**: No Node.js, no bundler, no npm packages required.
- **Fully responsive on all mobile devices**: Tested from 320px screens up to 4K desktop displays.
- **Light & Dark theme toggle**: Automatic OS preference detection and localStorage persistence.
- **Dual perspective switcher**: Instant switching between "Commercial Brands" and "NGOs & Donors".
- **Interactive Pilot Brief Generator**: Generates customized scopes in real-time with 1-click WhatsApp and Email links.
- **Mobile Offcanvas Navigation Drawer**: Touch-friendly hamburger menu with backdrop blur.
- **Sticky Mobile Bottom Quick Bar**: Quick WhatsApp, Phone call, and Pilot brief buttons on screens under 768px.
- **KDPA 2019 & Ethical AI Policy Modals**: Complete compliance documents viewable in accessible native dialogs.

## File Structure
- `index.html` — Semantic, accessible HTML5 structure
- `style.css` — Pure responsive CSS3 with CSS custom properties, grid, flexbox, and mobile breakpoints
- `app.js` — Lightweight vanilla JavaScript controller
- `../gebeya.webp` — Authentic East African market and retail visual

## How to Run
1. Double-click `index.html` to open it in any web browser (Chrome, Safari, Firefox, Edge).
2. Or serve it via any local server (e.g., Python `python -m http.server`, VS Code Live Server, or Nginx/Apache).
3. To deploy online: upload the files to GitHub Pages, Netlify, Vercel, or standard cPanel/Shared hosting.
